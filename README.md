# Bonsai World

Bonsai World is a native macOS application for organizing and caring for a bonsai collection. It is early in development; this repository holds the project foundation and documentation.

This README is only the project entry point. It is not product documentation.

Before making any changes, read [Documentation/START_HERE.md](Documentation/START_HERE.md).

New ideas discovered during development must be written in [Documentation/Project/00_Idea_Parking_Lot.md](Documentation/Project/00_Idea_Parking_Lot.md). Ideas must not be implemented immediately.

## Development launch

Build and open the app with [Scripts/build_and_launch.sh](Scripts/build_and_launch.sh). Do **not** open a `Bonsai Hub.app` by globbing DerivedData folders (that can launch an obsolete Debug build). Details: [Scripts/README.md](Scripts/README.md).
